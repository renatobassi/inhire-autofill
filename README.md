# InHire Autofill

Extensão Chrome (Manifest V3). O que ela faz está em [docs/PRD.md](docs/PRD.md).

## Carregar no Chrome

1. Abrir `chrome://extensions`.
2. Ativar o modo do desenvolvedor.
3. Carregar sem compactação e escolher esta pasta.

O perfil fica neste Chrome. O cadastro só salva depois da confirmação de que nada é enviado a um servidor.
